# Glance releases

The update feed (`appcast.xml`) and notarised downloads for Glance, a Mac dashboard for
unread Mail, Messages, Reminders and today's Calendar. Glance checks this feed once a day
and offers new versions; each zip is signed with Glance's update key.

To install by hand, download the newest `Glance-<version>.zip`, unzip it and drag Glance
into Applications.
